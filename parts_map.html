이름표 6종 확인

  • ✓ 헤더 — 맨 위 파란 영역 1개
  • ✓ 카드 — 흰 상자 10개 (제주대학교 홍보 카드)
  • ✗ 버튼 — 없음
  • ✗ 입력창 — 없음
  • ✓ 탭 — 상단 메뉴 링크 4개 (전환 기능은 없어 탭과 비슷한 메뉴)
  • ✗ 목록 — 없음 (카드 안은 <ul> 목록이 아닌 문단 10줄)

회색 이름표(푸터)는 요청하신 6종에는 없지만 화면에 있어 함께 표시했습니다. 카드 안의 문구는 줄여서 표시했습니다.
